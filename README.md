# Snake Game Project

A classic Snake game implementation using Python and Pygame.

## Features
- Interactive snake gameplay with arrow key controls
- Real-time score tracking
- Collision detection (walls and self)
- Difficulty level configuration (Easy, Medium, Hard)
- Game over detection with restart option

## Requirements
- Python 3.x
- Pygame

## Installation
```bash
pip install pygame
```

## Running the Game
```bash
python snake_game.py
```

## Game Controls
- **Arrow Keys**: Move the snake (UP, DOWN, LEFT, RIGHT)
- **Q**: Quit game after game over
- **C**: Play again after game over

## Game Rules
- The snake grows when eating food (green square)
- Score increases with each food eaten
- Game ends when the snake hits walls or itself
- The game can be restarted by pressing C after game over
